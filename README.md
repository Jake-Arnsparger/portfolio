# Jake Arnsparger — Engineering & Computer Science Portfolio

Live site: **[jake-arnsparger.github.io/portfolio](https://jake-arnsparger.github.io/portfolio/)**

Personal portfolio website showcasing my software engineering, embedded systems, and robotics projects as a Computer Science student at the University of Cincinnati (Class of 2030).

## Featured Projects

- **Autonomous Obstacle-Avoiding Arduino Robot:** Built in C++ using an MPU-6050 IMU with a Mahony orientation filter, servo-mounted ultrasonic scanner, and motor driver control (`robot demo.mp4`).
- **Autonomous LEGO Mindstorms EV3 Robotics Prototype:** Designed and programmed sensor-driven line following and automated bin-lifting logic in LabVIEW (`Labview demo.gif`).

## Tech Stack & Structure

- `index.html` — Main portfolio structure and project sections
- `style.css` — Responsive layout and styling
- `script.js` — Interactive UI behavior
- `Labview demo.gif` & `robot demo.mp4` — Hardware and software demo media
